# API (Rust)

This app is scaffolded for the debate orchestrator backend.

## Nx targets

- `nx build api` -> `cargo build`
- `nx serve api` -> `cargo run`
- `nx test api` -> `cargo test`
- `nx run api:clippy` -> `cargo clippy -- -D warnings`
- `nx run api:fmt` -> `cargo fmt --all -- --check`

Install Rust first if `cargo` is not available.
